# Animation Motion Library (`assets/animations/`)

Place standard humanoid animations here in `.fbx` or `.bvh` format:
- `walk.fbx`
- `idle.fbx`
- `run.fbx`
- `attack.fbx`
- `scare.fbx` / `ghost_float.fbx`

If any animation file is absent, Render3D automatically synthesizes smooth procedural humanoid keyframes!
